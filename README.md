## Overview

EXTRA Connect is the institutional omnichannel communication platform of the Sorteo Extraordinario de Colombia.

Its purpose is to centralize communications, campaigns, audiences, multimedia assets and analytics into a single enterprise platform.

## Technology Stack

### Frontend

- Next.js
- React
- TypeScript
- TailwindCSS
- shadcn/ui

### Backend

- Django
- Django REST Framework
- PostgreSQL
- Redis
- Celery

### Infrastructure

- Docker
- Nginx
- GitHub Actions
